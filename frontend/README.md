# Smart Voting Platform - Frontend

Angular frontend for the Smart Voting Platform.

This frontend provides a modern responsive voting interface with poll creation, voting, category filtering, search functionality, drag & drop support, and live UI updates.

---

# Features

* Create Polls
* Add Multiple Options
* Drag & Drop Option Reordering
* Instant Voting
* Search Polls
* Category Filtering
* Vote Progress Bars
* Toast Notifications
* Pagination
* Responsive UI
* Modern Glassmorphism Design

---

# Tech Stack

| Technology | Purpose |
|---|---|
| Angular 20 | Frontend Framework |
| TypeScript | Programming Language |
| Angular CDK | Drag & Drop |
| ngx-toastr | Toast Notifications |
| Bootstrap Icons | Icons |

# Run Frontend

```bash
ng serve
```

Application runs on:

```text
http://localhost:4200
```
